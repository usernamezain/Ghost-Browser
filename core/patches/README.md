# patches/

## Purpose
Ghost Browser's own C++/JS patches applied on top of the Zen Browser fork. These patches handle rebranding, telemetry stripping, privacy-hardening hooks, and integration points for the profile and theming systems.

## Roadmap Phase
Populated in **Phase 0** (Foundation) for rebranding/telemetry patches, and extended through **Phase 1** (Privacy Core) for privacy-specific engine modifications. Currently empty.

## Constraints
All patches must be individually documented with upstream references. Per Section 9: do not write engine patch logic from scratch — locate the relevant reference in `teaching/` first, read the actual patch, and adapt it.
