# userchrome/

## Purpose
The default userChrome.css / userContent.css configuration for Ghost Browser's standard UI appearance. This directory also contains the integration points for the theming engine defined in `theming/`.

## Roadmap Phase
Populated in **Phase 0** (Foundation) for the default theme, and extended in **Phase 3** (Theming & Customization Engine) for full theming engine support. Currently empty.
