# devtools/

## Purpose
Built-in professional developer and researcher tooling, implemented natively in the browser rather than as extensions. These tools give developers and OSINT researchers professional-grade capabilities without depending on the Chrome or Firefox extension store, maintaining Ghost Browser's offline-first and zero-dependency philosophy.

## Roadmap Phase
Populated in **Phase 4** (Built-In Developer & Researcher Tools, Weeks 14–20). Currently empty.

## Subdirectories
- `network-inspector/` — Network request inspector built on Gecko hooks
- `js-console-plus/` — Enhanced JS console with saved snippets and per-profile script injection
- `fingerprint-auditor/` — One-click self-test against CreepJS, BrowserScan, AmIUnique, and more
- `cookie-cookie-jar-ui/` — Visual cookie/storage control panel
