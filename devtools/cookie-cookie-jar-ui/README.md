# cookie-cookie-jar-ui/

## Purpose
A visual cookie and storage control panel that lets users see per-site storage (cookies, localStorage, sessionStorage, IndexedDB, cache), wipe storage with one click, and configure auto-purge behavior per profile. Implements the allow-list cookie model (no persistent cookies unless explicitly allowed) with clear visual feedback.

## Roadmap Phase
Populated in **Phase 1** (Privacy Core) for basic cookie control, extended in **Phase 4** (Developer & Researcher Tools) for the full visual panel. Currently empty.
