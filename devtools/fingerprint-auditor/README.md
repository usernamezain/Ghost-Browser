# fingerprint-auditor/

## Purpose
A one-click self-test tool that runs the current browser profile against multiple fingerprinting test suites — CreepJS, BrowserScan, AmIUnique, EFF Cover Your Tracks, and Fingerprint.com test pages — and reports a plain-language score plus exactly what's leaking. This is the user-facing counterpart of the developer verification protocol (Section 6).

## Roadmap Phase
Populated in **Phase 4** (Developer & Researcher Tools). Currently empty.

## Constraints
Results must be reported honestly — per Section 9, never invent security claims. If a vector is untested or partially mitigated, say so explicitly.
