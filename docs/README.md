# docs/

## Purpose
User-facing and developer-facing documentation for Ghost Browser. Covers plain-language user guides, the honest security model, developer build/contribution guides, preference references, theming documentation, threat models, and a FAQ.

## Roadmap Phase
Stubbed in **Phase 0** (Foundation). Fully populated in **Phase 6** (Polish, Audit, Public Release). Individual documents are populated as their corresponding features are built.

## Contents
- `user-guide/` — Plain-language guide for non-technical users
- `security-model.md` — Honest capabilities/limitations document
- `dev-guide/` — Build instructions, architecture overview, patching guide
- `preference-reference.md` — Every custom user_pref we ship, documented
- `theming-guide.md` — How to build/install a Ghost theme
- `faq.md` — Frequently asked questions
- `threat-models.md` — Worked examples of threat scenarios and recommended profiles
- `CHANGELOG.md` — Release changelog with fingerprint-relevant changes flagged
