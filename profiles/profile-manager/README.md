# profile-manager/

## Purpose
Handles creation, switching, deletion, and template management of isolated browser profiles. Built on Firefox's existing profile architecture (not a rewrite) with a native quick-switch UI — profile picker on new window, not buried in settings. Includes profile templates (e.g., "Banking," "Research," "Anonymous Browsing") with different default hardening levels.

## Roadmap Phase
Populated in **Phase 1** (Privacy Core). Currently empty.
