# theme-marketplace/

## Purpose
A local, offline-first theme browser (inspired by Zen Mods) that ships a curated set of themes with the browser and allows importing community themes from local files. No forced network dependency — the marketplace must function fully offline.

## Roadmap Phase
Populated in **Phase 3** (Theming & Customization Engine). Currently empty.

## Constraints
Per the non-negotiable constraints (Section 2): the marketplace must be offline-capable with no cloud dependency. Community themes are imported from local files, not downloaded from a required server.
