# title-bar-engine/

## Purpose
The frameless window mode and custom title bar system, enabling Ghost Browser's signature customizable chrome. Supports vertical tabs, sidebar layouts, and workspace switching (Zen-inspired, own implementation).

## Roadmap Phase
Populated in **Phase 3** (Theming & Customization Engine). Currently empty.

## Constraints
Custom title bars and frameless windows are notorious for breaking keyboard navigation and screen reader compatibility. An accessibility pass (Phase 6) is required before public release.
